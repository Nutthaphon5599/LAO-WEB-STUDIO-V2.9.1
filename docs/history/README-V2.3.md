# Lao Web Studio V2.3 — 3 Languages + CRM

เวอร์ชันนี้รองรับ 3 ภาษา: ลาว ไทย และอังกฤษ ทั้งหน้าเว็บไซต์และหน้า Admin

## สิ่งที่เพิ่ม
- ตัวเลือกภาษาในหน้า Admin
- ข้อความ Dashboard, CRM, ราคา และสถานะต่าง ๆ เปลี่ยนตามภาษา
- ฟอร์มผลงานเก็บข้อมูลแยก 3 ภาษาเหมือนเดิม
- หน้าเว็บไซต์และแบบฟอร์มขอใบเสนอราคาเปลี่ยนได้ 3 ภาษา
- คงการเชื่อมต่อ Supabase, ตาราง leads, projects, pricing และ Storage เดิม
