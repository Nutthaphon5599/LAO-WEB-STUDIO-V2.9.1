# Lao Web Studio V2.6 — Multi-page Admin

หน้า Admin ถูกแยกตามประเภทงาน โดยยังใช้ Supabase และฐานข้อมูลเดิมทั้งหมด

- admin.html — Dashboard
- admin-leads.html — ลูกค้า CRM
- admin-calendar.html — นัดหมาย
- admin-quotations.html — ใบเสนอราคา
- admin-files.html — ไฟล์ลูกค้า
- admin-projects.html — ผลงาน
- admin-pricing.html — ราคา
- admin-team.html — ทีมงาน

## การติดตั้ง
วางไฟล์ทั้งหมดทับ V2.5.1 ได้เลย ไม่ต้องรัน SQL ใหม่
