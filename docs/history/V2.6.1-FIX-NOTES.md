# V2.6.1 Fix

This release fixes the Supabase migration error:

`INSERT has more expressions than target columns`

The `roles_permissions` seed now contains exactly one role value plus twelve permission values,
matching the thirteen target columns.

## Installation
1. Upload all V2.6.1 files over V2.6.
2. Open Supabase SQL Editor.
3. Run `supabase-migration-v2.6.1-enterprise.sql`.
4. It is safe to rerun because tables use `if not exists`, columns use `if not exists`,
   and role rows use `on conflict ... do update`.

No existing leads, appointments, quotations, files, portfolio items, pricing, or employees are deleted.
