# Lao Web Studio V2.5 — Business CRM

## New
- Customer appointment calendar
- Client file uploads in private Supabase Storage
- Team management prepared for future staff
- Extended quotation fields and professional Print/PDF
- Dashboard upcoming-appointment metric
- WhatsApp and Email actions remain available
- Lao / Thai / English interface

## Install
1. Keep your existing V2.4 database.
2. Open `supabase-migration-v2.5.sql` in Supabase SQL Editor.
3. Run the entire file once.
4. Upload all website files to GitHub, replacing V2.4.

This migration is repeat-safe and does not delete existing leads, projects, prices, employees, or quotations.
