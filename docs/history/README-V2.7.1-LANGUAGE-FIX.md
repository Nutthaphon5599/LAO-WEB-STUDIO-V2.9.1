# Lao Web Studio V2.7.1 Language Fix

## Fixed
- Lao, Thai and English translations for Invoice, Kanban, Reports and Customer Updates
- Admin Login, Customer Login and Customer Portal translations
- One shared language selector on all new V2.7 pages
- Language persists in `localStorage` while moving between pages
- Invoice and task status translations
- Locale-aware dates and number formatting
- Lao kip remains the default currency; no amount conversion is performed

## Installation
Upload all V2.7.1 files over V2.7 in GitHub.

No new Supabase migration is required. V2.7.1 changes only frontend language behavior.
